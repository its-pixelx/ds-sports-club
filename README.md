# D&S Sports Club — Verified Sports & Nutrition Marketplace

> **Train Smarter. Fuel Honest.**  
> A full-stack athletic gear and sports nutrition platform built with TanStack Start, React 19, Tailwind CSS, and Framer Motion. Engineered for peak responsiveness across mobile, tablet, and desktop devices.

---

## ⚡ Key Highlights

- **Dual-Action Hero Section**:
  - **"Visit the Sports Club"**: Launches an interactive, step-by-step personalized onboarding questionnaire with real-time profile analysis and custom starter kit recommendation.
  - **"Go to Store"**: Direct, instant entry into the catalog of verified gear and nutrition.
- **100% Verified Edible Products & Authenticated Lab Reports**:
  - Every edible supplement includes transparent nutritional values, full ingredient disclosures, and Certificate of Analysis (CoA) reports from NABL-accredited labs verifying purity, zero amino spiking, and absence of heavy metals/banned substances.
  - Interactive CoA viewer with print/PDF export and batch certificate verification.
- **Top Tier Real-World Brands (15 Curated Products)**:
  - Optimum Nutrition Gold Standard Whey, MuscleBlaze Biozyme, Fast&Up Plant Protein, MuscleBlaze Super Gainer XXL, Creapure Creatine, Cellucor C4, Scivation XTEND BCAA, MuscleTech Multivitamins, Rogue Hex Dumbbells, Bowflex SelectTech 552, TheraBand Loops, Manduka PRO Mat, BlenderBottle V2, Under Armour Hoodie, Harbinger Gloves.
- **Amazon-Style Easy 10-Day Returns & Support**:
  - Transparent return guidelines, 3-step instant refund claim portal, drop-shipping hub verification, and return status tracker.
- **Minimalist Athletic Aesthetic & Peak Animations**:
  - Carbon slate `#090d14` background, subtle sky blue accents, high-contrast typography, and fluid Framer Motion spring micro-interactions.
- **Fully Responsive Architecture**:
  - Seamless navigation across mobile, small tablets (iPad Mini 768px), and large desktop viewports.

## 🛠 Tech Stack

- **Framework**: [TanStack Start](https://tanstack.com/start) with [TanStack Router](https://tanstack.com/router)
- **UI & State**: [React 19](https://react.dev/), [TanStack Query](https://tanstack.com/query)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://motion.dev/)
- **Components**: [Radix UI](https://www.radix-ui.com/), [Lucide React](https://lucide.dev/)
- **Testing**: [Vitest](https://vitest.dev/) with React Testing Library

## 🚀 Getting Started

### Prerequisites

- Node.js 18+ or 20+
- npm or bun

### Local Development

```bash
# 1. Clone repository
git clone https://github.com/its-pixelx/ds-sports-club.git
cd ds-sports-club

# 2. Install dependencies
npm install

# 3. Start local development server
npm run dev
```

Visit [http://localhost:3000](http://localhost:3000) to view the application.

### Running Unit Tests

```bash
npm run test
```

### Production Build

```bash
npm run build
```
